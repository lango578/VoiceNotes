【这是什么】
  供「语音笔记」Android App 使用的自建后端，包含：
   - 英文 → 中文逐句注释翻译（DeepSeek / 百度）
   - Whisper 语音转写（WebSocket 边录边出字 + 整段上传）
  已内置 Python 运行时与全部依赖，无需安装 Python/ffmpeg。

【快速开始】
  1. 把整个文件夹解压到电脑任意位置（路径最好不含中文/空格）
  2. 用记事本打开 .env，填入 DEEPSEEK_API_KEY（DeepSeek 密钥）
     （只做语音转写、不做中文注释时可留空）
  3. 双击 start.bat 启动服务
  4. 浏览器打开 http://127.0.0.1:8000/health
     看到 {"status":"ok","provider":"deepseek"} 即成功
  5. 手机 App 设置：
     - 识别引擎 = 自建后端识别（Whisper）
     - 后端地址 = http://<电脑局域网IP>:8000
     - 注释模式 = 后端翻译（地址同上）
     - 若 .env 设置了 AUTH_TOKEN，"后端 Token"填相同值

【局域网 IP 查询】
  命令行执行 ipconfig，找"无线局域网适配器"或"以太网适配器"的 IPv4 地址，
  例如 192.168.1.20。手机和电脑需在同一 Wi-Fi。

【开机自启（可选）】
  双击 install_autostart.bat —— 以后登录 Windows 自动在后台运行。
  移除自启：双击 uninstall_autostart.bat。

【首次使用 Whisper 转写】
  第一次录音转写时，会自动从 HuggingFace 下载模型（small 约 460MB，需联网）。
  下载一次后缓存在本文件夹，之后可离线使用。
  国内网络下载慢时，在 .env 末尾加一行：
     HF_ENDPOINT=https://hf-mirror.com
  然后重启 start.bat。

【常见问题】
  · 手机连不上 → 确认同一 Wi-Fi、防火墙放行 8000 端口：
      控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则
      → 端口 → TCP → 8000 → 允许连接
  · 端口被占用 → 在 .env 加 PORT=8001，然后启动，手机地址改成 8001
  · 翻译报错/没有中文注释 → 检查 .env 的 DEEPSEEK_API_KEY 是否正确
  · 忘记改 .env → 改完必须重启 start.bat

【卸载】
  删除整个文件夹即可（若注册过开机自启，先双击 uninstall_autostart.bat）。
